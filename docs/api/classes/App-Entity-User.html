implements UserInterface, PasswordAuthenticatedUserInterface, AuditableInterface uses AuditableTrait

User.php : 20

Account of a person using the platform (client or administrator).

The password is never stored in clear text: only its hash (bcrypt/argon2 chosen by Symfony) is saved. A new account is inactive until its owner clicks the link received by e-mail ($isVerified).
